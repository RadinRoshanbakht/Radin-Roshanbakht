# Fractio — ماشین حساب کسری

یک ماشین‌حساب شیک برای انجام عملیات روی کسرها (جمع، تفریق، ضرب، تقسیم)، با نمایش کسری، عدد مخلوط و اعشاری.

## نحوه آپلود در گیت‌هاب و انتشار (GitHub Pages)

1. یک ریپازیتوری جدید در گیت‌هاب بسازید (مثلاً `fraction-calculator`).
2. فایل‌های `index.html` و `manifest.json` را در آن آپلود کنید (Add file → Upload files).
3. به بخش **Settings → Pages** بروید.
4. در قسمت **Source**، شاخه (Branch) را `main` و پوشه را `/root` انتخاب کنید و **Save** بزنید.
5. بعد از حدود یک دقیقه، آدرسی شبیه به این در دسترس‌تان قرار می‌گیرد:
   `https://username.github.io/fraction-calculator/`
6. با گوشی اندروید این آدرس را باز کنید و از منوی مرورگر (⋮) گزینه **افزودن به صفحه اصلی / Add to Home Screen** را بزنید — دقیقاً مثل یک اپ نصب می‌شود و آیکون‌اش روی گوشی می‌آید.

## نکته درباره فایل APK
ساخت فایل APK واقعی نیاز به کامپایل با Android Studio/Gradle دارد. این نسخه به‌صورت اپ وب (PWA) طراحی شده که با «Add to Home Screen» دقیقاً مانند یک اپ نصب‌شده روی گوشی کار می‌کند، بدون نیاز به فایل APK یا نصب از منابع ناشناس.
